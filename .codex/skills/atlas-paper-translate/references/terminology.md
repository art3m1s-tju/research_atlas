# Autonomous-driving terminology

| English | Chinese | Keep unchanged |
|---|---|---|
| end-to-end autonomous driving | 端到端自动驾驶 | E2E |
| bird's-eye view | 鸟瞰视角 | BEV |
| world model | 世界模型 | world model when used as a model name |
| vision-language-action | 视觉-语言-动作 | VLA |
| model predictive control | 模型预测控制 | MPC |
| reinforcement fine-tuning | 强化微调 | RFT |
| closed-loop / open-loop | 闭环 / 开环 | benchmark names |
| trajectory planning | 轨迹规划 | dataset and metric names |
| collision rate | 碰撞率 | exact numeric values |
| drivable area conflict rate | 可行驶区域冲突率 | metric acronym if present |
| uncertainty-aware | 不确定性感知的 | module/model names |
| hallucination | 幻觉 | when discussing model-generated perception or reasoning |

Never translate model names, dataset names, paper titles in citations, author names, DOI strings, arXiv IDs, BibTeX keys, code identifiers, or LaTeX variable names.
